FAQ

Questions parents ask

Is it really free to start?
Yes. Every course has free starter quests with XP and badges. You only pay if you want the full course or live classes.
Which course should my child start with?
Pick their class above and we'll highlight the matching course. If they already code a bit, they can try the next course's free quests and see how it feels.
Do we need to install anything?
No. Python and the web editor run inside the browser. A laptop or desktop is best for Class 4 and up; younger kids are fine on a tablet.
How do I pay for a Pro course?
Send the course fee with bKash or Nagad "Send Money", then enter the Transaction ID on the course page. The course unlocks once the payment is verified, usually within a few hours.
Is this an official Cambridge course?
The lessons follow Cambridge curriculum frameworks and the O Level Computer Science 2210 syllabus, but this is an independent tutoring platform and isn't affiliated with or endorsed by Cambridge.
What's the difference between online and onsite tuition?
Online classes run live on Google Meet or Zoom. Onsite classes are in person at Dhaka. Both include Pro access to the student's class course.
